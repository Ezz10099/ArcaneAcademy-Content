# Arcane Academy audio

Runtime audio for Arcane Academy. Music is loaded on demand through `src/platform/game-audio.js`; effects and music keep separate user volume controls.

## Accepted music identities

- `academy.ogg` — Academy/home music. The current full-length generated theme is SPCK accepted.
- `expedition.ogg` — Expedition/Formation music. User accepted the supplied Stable Audio 3 composition on 2026-09-22, including its natural end-to-start loop feel. The composition is preserved; the runtime file is only re-encoded to compact Ogg/Vorbis.
- `battle.ogg` — accepted Wild Forest regular-battle theme. Integrated and tested in SPCK on 2026-09-22; the user described it as very awesome in-game.

Routing is intentionally global by screen identity: Campaign/Expedition and Formation use `expedition`; active battles use `battle`; Academy and non-expedition screens use `academy`; battle results stop music for the result cue.

The six earlier synthetic per-Location themes were retired from runtime when the global Expedition/Battle soundtrack direction was adopted. `scripts/generate-location-audio.py` is historical provenance only and must not be used to repopulate those retired runtime files.

## Action and combat cues

- `01_ui_select.ogg` — UI selection.
- `02_melee_hit.ogg` — fallback basic-hit cue for enemies and combatants without a dedicated sound.
- `12_cinder_basic.wav` — Cinder Vale / Ember Bash; selected Adobe Firefly candidate #2 (`621560 FBA`).
- `13_yssa_basic.wav` — Yssa Driftborn / Cryo Shot; selected Adobe Firefly candidate #4 (`821833 1hy`).
- `14_lumen_basic.wav` — Lumen Solis / Prism Bolt; selected Adobe Firefly candidate #2 (`807406 nEY`).
- `15_cinder_ultimate_1.wav` … `18_cinder_ultimate_4.wav` — four Cinder / Blazing Charge Firefly variants; the runtime rotates them per use.
- `19_yssa_ultimate_1.wav` … `22_yssa_ultimate_4.wav` — four Yssa / Blizzard Barrage Firefly variants; the runtime rotates them per use.
- `23_lumen_heal_1.wav` … `26_lumen_heal_4.wav` — four Lumen healing variants used by Lumen Mend and Grand Resonance; the runtime rotates them per healing action.
- `03_arcane_cast.ogg` — fallback skill/cast for actions without a dedicated cue.
- `04_ultimate_release.ogg` — fallback ultimate release for trainees/enemies without a dedicated ultimate cue; playback starts at its 0.65-second release point.
- `05_victory.ogg` / `06_defeat.ogg` — battle result.
- `07_summon.ogg` — normal successful summon reveal.
- `08_summon_rare.ogg` — enhanced reveal when a pull contains Epic or Legendary.
- `09_train.ogg` — successful training.
- `10_reward.ogg` — successful quest/idle/battle reward collection.
- `11_formation.ogg` — actual squad or row change.

Success cues do not play for failed actions, unchanged formations, or rerendering existing summon results. A ten-pull produces one reveal cue.

## Verification

Audio checks cover gesture gating, one active music loop, Expedition/Battle/Academy routing, pause/visibility, result silence, effect deduplication, persistence, voice limits, stale loads, and fetch retry behavior. Runtime assets remain subject to the repository's hard `< 10 MiB` final-assets budget.
